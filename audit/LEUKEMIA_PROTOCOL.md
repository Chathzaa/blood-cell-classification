# Restored scope: cell detection and ALL screening

The user clarified that the required disorder is leukemia, without anemia or sickle cell screening. The available labelled disorder data supports acute lymphoblastic leukemia (ALL), not all leukemia types. Preserve the verified cell pipeline and add a newly evaluated ALL screening branch. The earlier WBC-focused release remains archived.

## Decisions fixed before new ALL model fitting or test prediction

1. Use only data/Leukemia/Original for fitting inputs. Build a reproducible stain-focused second view directly from each original, with no class-specific operations or supplied processed images. Exact duplicates and conservatively identified similar fields share a group. A group never crosses partitions. Patient IDs are absent; this is a grouped image study, not patient-independent evaluation.
2. Collapse exact decoded-pixel duplicates. Group remaining pairs at perceptual hash distance <=4 under eight rotations/reflections. For distances 5 to 10, also require affine SIFT registration: ratio test 0.75, at least 12 inliers, inlier fraction >=0.60, and coverage >=0.10 of each field. Grouping is deliberately conservative; visually inspect representative accepted pairs. Quarantine groups with conflicting class labels.
3. Assign approximately 60% training, 20% validation and 20% test using five stratified group folds, shuffled with seed 2026. Fold 0 is test, fold 1 validation, remaining folds training. Do not reuse any supplied leukemia checkpoint.
4. The stain-focused view retains pixels above an Otsu threshold on HSV saturation and sets the background to neutral grey. It is an image transformation, not an expert cell/nucleus mask. Use exactly the same code at training and inference. Audit the supplied Segmented files only as historical material.
5. Extract frozen 1280-dimensional ImageNet YOLOv8 nano classification features for the original and stain-focused views. Fit separate regularized, class-balanced multinomial logistic heads on training features; fit standardization on training only. Select C from {0.01,0.1,1,10} by validation macro F1, breaking ties toward smaller C. Frozen features make this additional experiment feasible on CPU and isolate the contribution of the input/review design.
6. Fit one temperature per head by validation negative log likelihood. Compare original-only, stain-only and equal posterior averaging. Learned fusion weights are not tuned. ALL probability is the sum of Early, Pre and Pro probabilities; the four labels do not represent severity.
7. Proposed review rule: accept a binary result only when both views agree benign versus ALL and each supports that binary result above a validation-selected threshold. If accepted as ALL, report a subtype only when both views agree on the most likely malignant subtype and both conditional subtype probabilities exceed a separately selected threshold. Otherwise keep the ALL screening flag and request subtype review.
8. Thresholds come from {0.50,0.55,...,0.95}. Choose the smallest with >=99% empirical binary correctness and at least 20 retained benign plus 20 retained ALL validation images. For subtype acceptance, require >=95% empirical correctness and >=20 validation images in each predicted malignant category. If no threshold qualifies, that decision level always requests review. These are engineering targets, not guarantees. Report any failure to transfer on test.
9. Evaluate four-category accuracy/macro F1/MCC, binary sensitivity/specificity/AUROC and confusion counts. Report review coverage, retained errors, per-class coverage, and confidence-only comparison at matching coverage through risk-coverage curves. Use grouped bootstrap intervals where practical; report image counts and group counts explicitly.
10. Prespecified stress tests: Gaussian blur (5x5, sigma 1.0) and a fixed colour gain (BGR 0.90,1.00,1.10), without retraining or threshold retuning. These are controlled perturbations, not external clinical validation. Report them even if the proposed rule fails to improve on a baseline.

The candidate contribution is the measured utility and limitations of view-consistent hierarchical review within a source-audited cell detection and ALL screening workbench. Existing literature already covers CNN classification, view comparisons and selective classification; do not claim those general ideas as new or promise a performance improvement before observing the fixed tests.
